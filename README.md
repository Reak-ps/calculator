# Calculator 🧮

A simple command-line calculator written in C++.

## What does it do?

Takes two numbers and an operator as input and calculates the result. Supports addition, subtraction, multiplication, and division.

## How to run

1. Open the project in CLion
2. Press the Play button ▶️
3. Follow the prompts

## Example

```
Enter first number: 10
Enter operator (+, -, *, /): /
Enter second number: 3
10 / 3 = 3.33333
```

## Features

- Addition, subtraction, multiplication, division
- Decimal number support (double precision)
- Division by zero protection

## Built with

- C++20
- CLion
